ReservaYa

reservaya-umber.vercel.app

Plataforma de reservas para restaurantes de Paraguay, hecha en equipo. Construí la API completa con autenticación JWT y llevé el proyecto a producción con dos servicios conectados.

Django REST FrameworkJWTPostgreSQLNext.jsTypeScriptTailwind CSS
Ver el caso completo
Problema
En Paraguay, reservar mesa en un restaurante depende de llamadas o WhatsApp, sin un sistema centralizado que muestre disponibilidad real ni ordene las reservas.
Solución
API REST en Django REST Framework con autenticación JWT, filtros y modelos de restaurantes y reservas, consumida por un frontend en Next.js (App Router) con TypeScript y Tailwind CSS. Construí el backend completo (modelos, endpoints, JWT y carga de restaurantes reales de Asunción, Encarnación y Ciudad del Este) y el despliegue: base de datos PostgreSQL y API en Render, frontend en Vercel.
Qué demuestra
Trabajo en equipo en un proyecto full stack real, diseño de una API con autenticación desde cero y un despliegue en producción con servicios conectados entre sí.

IR Barber Supply

irbarber-demo.vercel.app · demo del prototipo

E-commerce de insumos para barberías con precios mayorista y minorista, en JavaScript vanilla y sin frameworks.

JavaScript ES6+Módulospub/sublocalStorage
Ver el caso completo
Problema
Las barberías no tenían dónde comprar insumos profesionales online con precios diferenciados entre minorista y mayorista.
Solución
Estado global con patrón pub/sub (eventos personalizados), carrito persistido en localStorage con sincronización entre pestañas y reglas de negocio reales: tarifa dual, descuentos por volumen y pedido mínimo mayorista, en guaraníes.
Qué demuestra
Diseñar una arquitectura de estado desde cero y modelar lógica de negocio real para un mercado específico.
